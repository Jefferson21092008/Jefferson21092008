A production-oriented vehicle rental management system built with FastAPI and PostgreSQL.

The project evolved from a simple OOP application into a full-stack system with authentication, payments, reservations, maintenance, reporting, background processing and advanced backend architecture.

### Highlights

- Layered architecture:
  **Router → Service → Repository → SQLAlchemy**
- PostgreSQL + Alembic migrations
- JWT access tokens + refresh token rotation
- RBAC and granular permissions
- Redis caching and rate limiting
- Background jobs and dedicated workers
- Transactional Outbox
- Event-driven internal architecture
- PostgreSQL concurrency control
- `SELECT FOR UPDATE`

- Docker hardening
- CI/CD with GitHub Actions
